One sick-day excuse, 135 characters, in the voice of someone texting their boss:

> Can't come in today — my eye is twitching so hard it keeps winking at strangers, and HR has asked me to stop flirting with the clients.

The joke: a real symptom (an eye twitch) escalates into an HR problem. The
punchline — "stop flirting with the clients" — arrives on the last words,
and the premise appears nowhere in the field of 114 entries: no sneezed-out
back, no locked bathroom, no cat with the car keys, no parrot, no toddler
with a marker.

## Run it

```sh
python3 main.py
```

Writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
